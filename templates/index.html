Welcome to ReguAI Local ML v2.0

Runs 100% on your laptop. No API key. No internet needed. Powered by TF-IDF + Multinomial Naive Bayes classifier and extractive NLP summarisation.

🔢
TF-IDF
Term Frequency-Inverse Document Frequency — weights medical terms by importance across all documents
📊
Naive Bayes
Multinomial Naive Bayes — probabilistic classifier trained on CDSCO SAE patterns with Laplace smoothing
🔍
NER + Regex
Named Entity Recognition using pattern matching for PII/PHI detection in Indian medical documents
🗄️
SQLite DB
Local database stores all documents, results, and training data — fully offline, no cloud needed
Quick Start
  1. Server is already running — no setup needed
  2. Choose a module from the sidebar
  3. Load a sample or paste your document text
  4. Click Run — results are instant and saved to database
